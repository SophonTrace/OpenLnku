<h1 align="center">OpenLnku</h1>
<p align="center">让网络连接，简单而清晰。</p>
<p align="center"><a href="https://github.com/SophonTrace/OpenLnku/releases/latest">下载 Windows 版</a> · <a href="README.en.md">English</a> · <a href="LICENSE">AGPL-3.0</a></p>

OpenLnku 是面向 Windows 的现代校园网认证客户端，以 C++20 和 Qt Quick 构建。白色与蓝色的简约界面，把认证状态、网络路径、流量和测速结果放在易于理解的位置。选择网卡、输入账号，一次连接；之后由托盘、断线重连与开机自启动照顾日常使用。

当前认证配置面向 **JLU 校园网 / 吉林大学校园网认证（DrCOM）**。这是独立开源项目，与学校及官方客户端无隶属关系；其他学校是否兼容需要验证相应协议与参数。

## 功能一览

| 功能 | 体验 |
| --- | --- |
| 现代界面 | 蓝白配色、清晰的状态卡片、统一的线条图标；默认 960 × 620，适配高 DPI |
| 选择与绑定网卡 | 自动枚举实体网卡，认证 socket 绑定所选接口与源地址，显示实际认证路径和系统路由 |
| 自动恢复 | 确认服务器认证与心跳后才显示已连接；断线退避重试，休眠唤醒重新建立会话 |
| 开机自启动 | 自启动、自动连接、断线重连默认开启；升级保留原有明确选择 |
| 网络测速 | 系统路由 / 实体网卡直连可选，国内 / 海外 / 自动节点，出口 IP、上下行、延迟、抖动和实时曲线 |
| 流量统计 | 当前所选网卡的上下行速率、累计收发流量 |
| 双语与托盘 | 设置中即时切换简体中文 / English；关闭窗口驻留托盘，托盘可连接、断开和退出 |
| 凭据与更新 | 当前用户 DPAPI 保存密码，签名清单与 SHA-256 校验应用更新，失败回滚 |

## 看清网络的每一条路径

![OpenLnku 网络测速](docs/images/network.png)

系统路由模式衡量当前代理 / TUN 通道，实体网卡直连模式衡量选定的物理接口。可选国内节点、海外节点，或让自动选择检查可达性和连接响应；界面同时呈现出口 IP 与测试节点，方便判断结果对应哪条路径。

## 你的连接，你的偏好

![OpenLnku 设置](docs/images/settings.png)

启动行为、语言、托盘、通知、凭据和应用更新集中在设置页。单账号设计减少切换成本，也不弹出校园网资讯页面。

## 使用

发布包可解压后双击运行，也可使用当前用户安装器。无需以管理员身份运行。
1. 完全退出其他认证客户端，避免占用 UDP 61440。
2. 打开 OpenLnku，在“网络”中选择实际接入网络的物理网卡。
3. 输入账号密码，点击“连接”。收到服务器的认证与首轮心跳确认后显示“认证已通过”。
4. 关闭窗口默认保留托盘；需要结束认证时选择“断开连接”或托盘中的“退出 OpenLnku”。

新用户的开机自启动、启动时自动连接和自动重连默认开启。自动连接需要已保存的账号密码。已有的明确关闭选择在升级时保留。手动断开会暂停本次恢复，直到再次主动连接。密码由当前 Windows 用户的 DPAPI 保护；取消记住密码或清除账号会删除已保存的凭据。

认证服务器为 10.100.61.3:61440 / UDP。认证通道绑定选定的物理接口；系统目标路由另行显示。互联网检测默认按需，可设置 HTTPS 地址并开启每五分钟检测。结果仅代表检测地址的访问情况，不会因外部访问失败就注销认证或改变代理设置。

概览显示状态、最近心跳、在线时长、单账号与网卡流量；网络页管理网卡和检查；日志页支持筛选、复制和导出；设置页管理启动、通知、窗口关闭行为及凭据。流量是所选实体网卡在本次运行期间的收发统计，包含系统流量；重启会重新计数。HTTPS 耗时是整次检测的用时。

## 安装、升级与卸载
安装包默认安装到当前用户 Programs/OpenLnku，支持 Windows 10+ x64，不要求管理员权限。安装完成页不会默认启动程序。

升级前请从托盘退出 OpenLnku。升级保持安装路径、账号和偏好，并根据受管文件清单删除过时的包内文件。未知用户文件保留。安装与卸载不可并发执行，运行中的客户端不会被强行结束。

原 OpenNex 用户的账号、密码、语言和连接偏好会迁移到 OpenLnku；安装升级沿用原安装目录，切换开机启动项和卸载登记，并清理旧版受管程序与快捷方式。设置中可即时切换中文或英文。诊断日志的复制、导出保留中文规范文本，便于统一排查。

卸载默认保留账号和偏好；勾选“同时删除保存的账号、密码与偏好”可清除。对应当前安装路径的开机启动项会移除。便携版不注册卸载项，其偏好存储与安装版相同；跨路径使用时可在设置中重新启用开机自启动。

程序和安装器尚未进行代码签名。开源来源与许可见 LICENSE、THIRD_PARTY.md 和 Qt-Licenses；附带 Source 目录可用于重新构建和替换动态库。

## 网络测速与应用更新
网络页提供系统路由和实体网卡直连两种测速模式，并提供自动选择、国内节点、海外节点。自动选择在当前通道内检查国内昆山和 Cloudflare 节点，选择可用且连接响应更快的节点；手动选择不会跨区域回退。各模式与节点选项分别保留结果。系统模式跟随 Windows 代理与 TUN；直连模式绑定所选物理接口和 IPv4 地址，出口 IP 查询与测速使用该通道。TUN 捕获 DNS 时，域名解析可使用系统 HTTPS DNS 查询取得真实地址，测速连接仍绑定实体接口。显示下载、上传、HTTP 延迟、抖动、实时曲线和测试流量；直连失败不会回退到代理模式。出口 IP 查询服务不可用时显示“—”，不冒充本地地址。

国内节点使用 Speedtest.net 公布的昆山节点 HTTPS 传统 HTTP 接口；海外节点使用 Cloudflare，具体机房由其网络路由选择，底部显示实际机房代码。本应用的有时限单连接 HTTPS 吞吐测试不等同于 Ookla 或 Cloudflare 官方测速算法，也不保证跑满运营商带宽。节点服务可用性取决于网络和服务方。

设置页从 [GitHub Releases](https://github.com/SophonTrace/OpenLnku/releases) 检查更新。客户端验证内置公钥对应的 ECDSA P-256 清单签名和更新包 SHA-256，用户点击“重启并更新”后退出、备份并替换受管文件，保留账号、偏好和未知用户文件。替换失败会恢复旧版；检测到未完成的更新记录时提供“恢复上次更新”。若旧版本已无法启动，可重新运行安装器恢复。更新签名保护发布包来源，不能替代 Windows Authenticode 代码签名。

发布者私钥保存在本机 `.private`，由当前 Windows 用户 DPAPI 加密；绝不可提交到仓库或随发布包分发。发布用 `tools/sign-release.ps1` 生成 `update.json` 和 `update.sig`，公钥位于 `packaging/update-public-key.hex`。私钥备份需保留在独立安全位置。

## 构建与离线验证
需要 Windows x64、Visual Studio C++ 工作负载、Windows SDK 和 Qt 6.8.3 MSVC x64。发布脚本使用 PowerShell 7.4 或更新版本；本次使用 7.6.5 验证。Qt 默认位于 .deps/Qt/6.8.3/msvc2022_64，也可指定 QT_ROOT。VERSION.txt 是发布版本来源。

```powershell
./tools/build.cmd
./tools/package.ps1
./tools/verify-package.ps1
./tools/installer.ps1
./build/OpenLnku.exe --demo
```

普通启动使用真实认证；--demo 只使用合成响应，不验证账号密码，不创建认证 UDP socket，不写真实开机启动项。--capture、--demo-connect、--settings-file、--test-identity 与预览参数仅允许离线模式，不能误触真实认证。

实网兼容验收与离线构建验收分开记录。OpenLnku 为独立项目。
