# OpenNex
Windows 网络认证客户端，C++20 认证核心与 Qt Quick 界面。

## 使用

发布包可解压后双击运行，也可使用当前用户安装器。无需以管理员身份运行。
1. 完全退出其他认证客户端，避免占用 UDP 61440。
2. 打开 OpenNex，在“网络”中选择实际接入网络的物理网卡。
3. 输入账号密码，点击“连接”。收到服务器的认证与首轮心跳确认后显示“认证已通过”。
4. 关闭窗口默认保留托盘；需要结束认证时选择“断开连接”或托盘中的“退出 OpenNex”。

新用户的开机自启动、启动时自动连接和自动重连默认开启。自动连接需要已保存的账号密码。已有的明确关闭选择在升级时保留。手动断开会暂停本次恢复，直到再次主动连接。密码由当前 Windows 用户的 DPAPI 保护；取消记住密码或清除账号会删除已保存的凭据。

认证服务器为 10.100.61.3:61440 / UDP。认证通道绑定选定的物理接口；系统目标路由另行显示。互联网检测默认按需，可设置 HTTPS 地址并开启每五分钟检测。结果仅代表检测地址的访问情况，不会因外部访问失败就注销认证或改变代理设置。

概览显示状态、最近心跳、在线时长、单账号与网卡流量；网络页管理网卡和检查；日志页支持筛选、复制和导出；设置页管理启动、通知、窗口关闭行为及凭据。流量是所选实体网卡在本次运行期间的收发统计，包含系统流量；重启会重新计数。HTTPS 耗时是整次检测的用时。

## 安装、升级与卸载
安装包默认安装到当前用户 Programs/OpenNex，支持 Windows 10+ x64，不要求管理员权限。安装完成页不会默认启动程序。

升级前请从托盘退出 OpenNex。升级保持安装路径、账号和偏好，并根据受管文件清单删除过时的包内文件。未知用户文件保留。安装与卸载不可并发执行，运行中的客户端不会被强行结束。

卸载默认保留账号和偏好；勾选“同时删除保存的账号、密码与偏好”可清除。对应当前安装路径的开机启动项会移除。便携版不注册卸载项，其偏好存储与安装版相同；跨路径使用时可在设置中重新启用开机自启动。

程序和安装器尚未进行代码签名。开源来源与许可见 LICENSE、THIRD_PARTY.md 和 Qt-Licenses；附带 Source 目录可用于重新构建和替换动态库。

## 网络测速与应用更新
网络页提供系统路由和实体网卡直连两种测速模式，各自保留结果。系统模式跟随 Windows 代理与 TUN；直连模式绑定所选物理接口和 IPv4 地址，出口 IP 查询与测速共用该通道。显示下载、上传、HTTP 延迟、抖动、实时曲线和本次测试数据量。测速使用 Cloudflare 节点，消耗网络流量，结果代表该节点的 HTTPS 吞吐；直连失败不会回退到代理模式。

设置页从 [GitHub Releases](https://github.com/SophonTrace/OpenNex/releases) 检查更新。客户端验证内置公钥对应的 ECDSA P-256 清单签名和更新包 SHA-256，用户点击“重启并更新”后退出、备份并替换受管文件，保留账号、偏好和未知用户文件。替换失败会恢复旧版；检测到未完成的更新记录时提供“恢复上次更新”。若旧版本已无法启动，可重新运行安装器恢复。更新签名保护发布包来源，不能替代 Windows Authenticode 代码签名。

发布者私钥保存在本机 `.private`，由当前 Windows 用户 DPAPI 加密；绝不可提交到仓库或随发布包分发。发布用 `tools/sign-release.ps1` 生成 `update.json` 和 `update.sig`，公钥位于 `packaging/update-public-key.hex`。私钥备份需保留在独立安全位置。

## 构建与离线验证
需要 Windows x64、Visual Studio C++ 工作负载、Windows SDK 和 Qt 6.8.3 MSVC x64。发布脚本使用 PowerShell 7.4 或更新版本；本次使用 7.6.5 验证。Qt 默认位于 .deps/Qt/6.8.3/msvc2022_64，也可指定 QT_ROOT。VERSION.txt 是发布版本来源。

```powershell
./tools/build.cmd
./tools/package.ps1
./tools/verify-package.ps1
./tools/installer.ps1
./build/OpenNex.exe --demo
```

普通启动使用真实认证；--demo 只使用合成响应，不验证账号密码，不创建认证 UDP socket，不写真实开机启动项。--capture、--demo-connect、--settings-file、--test-identity 与预览参数仅允许离线模式，不能误触真实认证。

实网兼容验收与离线构建验收分开记录。OpenNex 为独立项目。
