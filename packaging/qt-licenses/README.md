Qt 6.8.3 third-party license materials

License texts are complete files from the official Qt GitHub mirror, pinned to tag v6.8.3. Each module retains its own LICENSES directory:
- https://github.com/qt/qtbase/tree/v6.8.3/LICENSES
- https://github.com/qt/qtdeclarative/tree/v6.8.3/LICENSES
- https://github.com/qt/qtsvg/tree/v6.8.3/LICENSES

The SPDX SBOM files were copied from the Qt 6.8.3 win64_msvc2022_64 SDK's installed sbom directory. They are grouped by module under sbom/. `manifest.json` records each file's source, byte count, and SHA-256 digest.
