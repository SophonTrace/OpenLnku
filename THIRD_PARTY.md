# 来源与许可

本项目以 AGPL-3.0 发布，许可证全文见 LICENSE。

认证报文研究参考 drcoms/jlu-drcom-client，固定版本
`2ba09ce24041c4ab7021ddbc07a366e9ae3e1c5d`，尤其是 Java 的协议文档和
ByteUtil / DrcomTask 实现。原项目许可为 AGPL-3.0；相关原作者与贡献者
版权保留。新核心由主开发代理按该资料重新编写，修正校验与会话管理，
并不声称报文算法和字段研究是原创。

https://github.com/drcoms/jlu-drcom-client

审阅时还参考 drcoms/dr-jlu-win32；该参考客户端代码未链接进产品。

https://github.com/drcoms/dr-jlu-win32

UI 为本项目的 QML 实现，参考 Clash Verge 的简洁布局风格，没有复制其 UI 源码、图标或品牌资产。

Qt 6 动态链接库按分发包所附许可证提供，使用到的模块主要为 Qt Base、
Qt Declarative 和 Qt SVG；其 LGPL/GPL 与第三方说明随便携包提供。
Qt 官方源码、源代码获取方式和许可详见 https://www.qt.io/licensing
及 https://download.qt.io/archive/qt/6.8/6.8.3/single/ 。
打包过程中必须保留 LGPL 动态库替换能力及许可文件；发行前仍需检查
所打包模块的完整许可材料。

MSVC 运行库来自 Visual Studio，按微软随产品提供的再分发条款使用。

安装器由 NSIS 3.13 编译，其版权/许可材料见 Source/packaging/NSIS-COPYING.txt。
