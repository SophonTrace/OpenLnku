# OpenNex 1.1.0

Windows 10+ x64。C++20、Qt 6.8.3，单账号认证客户端。

## 变化

- 新版布局首次默认使用 960×620 逻辑像素；之后保留用户调整的窗口尺寸。
- 概览交换连接路径与流量吞吐面板位置。
- 网络测速采用蓝色仪表、蓝绿曲线、圆形指标图标与坐标刻度，支持系统路由和实体网卡直连，并分别显示出口 IP、吞吐、HTTP 延迟、抖动及测试流量。
- 直连绑定物理接口和源 IPv4；失败不会回退到系统路由，不修改代理和全局路由。系统代理发现隔离在可取消的子进程中。
- 设置页提供 GitHub Releases 更新，验证 ECDSA P-256 签名清单、包大小、SHA-256、包内受管文件清单，再由内置助手退出并更新。
- 升级保留账号、偏好和未知用户文件；同目录原子替换、备份、失败回滚，启动时识别未完成记录并提供恢复入口。
- 密码仍由当前用户 DPAPI 保护；自启动、自动连接、自动重连的既有选择保留。

## 验证

- 五组离线 CTest 通过：认证协议与状态机、流量、测速状态、更新验签、控制器和设置行为。
- Windows PowerShell 5.1 更新助手八项场景通过：升级与未知文件保留、过时文件删除、注入失败逐字节回滚、损坏包拒绝、路径穿越拒绝、重复项拒绝、未知文件冲突拒绝、中断恢复和备份缺失拒绝。
- 离线截图使用合成账号和地址，不发送认证 UDP 数据。

## 范围

HTTP 延迟包含请求往返，不是 ICMP 延迟。网卡流量是当前进程期间实体接口的系统收发计数，不代表计费流量。测速结果只反映所选节点与路径。

更新清单签名不等于 Windows Authenticode；本版 EXE 和安装器尚无 Windows 代码签名。若中断后应用无法启动，可重新运行安装器恢复。现有正在运行的客户端及认证会话不因测试被强制结束。
