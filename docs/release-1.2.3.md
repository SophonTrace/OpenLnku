# OpenLnku 1.2.3

修复应用内更新时，旧版已退出但更新未完成、程序未重新启动的问题。

- 更新助手确认就绪后，客户端才会退出。
- 助手准备失败会在界面显示原因，当前客户端继续运行。
- 修正更新完成后的窗口启动方式，补充更新失败记录。
- 兼容不同启动环境下的 Windows PowerShell 模块路径，避免助手静默启动失败。

**从 1.2.0 或 1.2.2 升级：**这两个版本内置的更新助手存在上述问题。若应用内更新失败，请退出托盘中的旧版，用新版安装包覆盖安装；便携版请将新版完整解压到新目录后打开。请勿只复制单个 EXE。账号与设置由当前 Windows 用户保留。

## 下载

- `OpenLnku-1.2.3-setup-x64.zip`：解压后运行安装器。
- `OpenLnku-1.2.3-setup-x64.exe`：直接运行安装器。
- `OpenLnku-1.2.3-windows-x64.zip`：便携版，完整解压后运行。

支持 Windows 10 / 11 x64。应用内更新使用发布清单签名和 SHA-256 校验；程序与安装包目前尚无 Windows 代码签名证书。
