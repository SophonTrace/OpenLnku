# OpenLnku 1.2.3

快速连接，断线自动重连。

本次更新完善了网络页面，增加 IPv4 / IPv6 测速、出口信息和 DNS 检测，并优化测速布局，修复应用内更新后未自动启动的问题。

## 更新内容

- 修复重启更新后程序未自动启动的问题。

- 网络测速支持系统路由和实体网卡直连，可选择自动、国内或海外节点。
- 支持自动 IP 协议、IPv4 与 IPv6。
- 标准测速下载 10 秒、上传 7 秒；延长模式为 20 秒、15 秒。
- 新增出口信息卡显示国家、IP、服务商、位置、时区，支持隐藏或复制 IP。
- 新增 DNS 泄露检测。

## 下载与升级

- `OpenLnku-1.2.3-setup-x64.zip`：解压后运行安装器。
- `OpenLnku-1.2.3-setup-x64.exe`：直接下载安装器。
- `OpenLnku-1.2.3-windows-x64.zip`：便携版，完整解压后运行。

支持 Windows 10 / 11 x64。已安装用户可在设置中检查更新；手动升级前请先从托盘退出旧版。

**旧版升级提示：**1.2.0 / 1.2.2 若出现更新后未自动启动，请手动安装 1.2.3 一次；便携版请完整解压到新目录。账号和设置会保留。

## 检测说明

测速反映当前路径到所选节点的传输表现。IPv4 / IPv6、代理分流和节点负载可能产生不同结果。

DNS 检测没有取得记录或只取得部分记录时会显示无法完整判断。

出口与 DNS 查询使用 Cloudflare / IPLeak 在线服务
