# OpenLnku 1.2.2

快速连接，断线自动重连。

本次更新完善了网络页面，增加 IPv4 / IPv6 测速、出口信息和 DNS 检测，并优化测速布局。项目介绍使用经过隐私遮挡的实际使用截图。

## 更新内容

- 网络测速支持系统路由和实体网卡直连，可选择自动、国内或海外节点。
- 支持自动 IP 协议、IPv4 与 IPv6；国内使用上海大学服务，海外使用 Cloudflare 实际调度机房。
- 标准测速下载 10 秒、上传 7 秒；延长模式为 20 秒、15 秒。连接预热后再开始测量。
- 仪表与曲线基础量程提升至 1200 Mbps；节点、协议和时长统一放入“测速选项”。
- 新增出口信息卡，显示国旗、国家、IP、服务商、位置、时区和近似坐标，支持隐藏或复制 IP。
- 新增 DNS 泄露检测，列出实际观测到的解析器；普通 DNS 查询和 Fake-IP 连接触发的记录分别标注。
- 保持默认窗口比例、完整测速仪表和曲线，移除 DNS 卡片底部解释小字。
- 更新中英文项目介绍，展示真实概览、测速和设置截图；账号、密码栏及网络地址已遮挡。

## 下载与升级

- `OpenLnku-1.2.2-setup-x64.zip`：解压后运行安装器。
- `OpenLnku-1.2.2-setup-x64.exe`：直接下载安装器。
- `OpenLnku-1.2.2-windows-x64.zip`：便携版，完整解压后运行。

支持 Windows 10 / 11 x64。已安装用户可在设置中检查更新；手动升级前请先从托盘退出旧版。升级保留账号与偏好。

## 检测说明

测速反映当前路径到所选节点的传输表现。IPv4 / IPv6、代理分流和节点负载可能产生不同结果。

DNS 检测没有取得记录或只取得部分记录时会显示无法完整判断。地区一致不代表没有泄露；浏览器独立设置的安全 DNS 不在此检测范围内。

出口与 DNS 查询使用 Cloudflare / IPLeak 在线服务，不发送校园网账号密码。程序与安装包目前尚无 Windows 代码签名证书；应用内更新使用发布清单签名和 SHA-256 校验。
